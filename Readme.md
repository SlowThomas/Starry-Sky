# Starry Sky

This is a 3D Space Shooter Game, written in plain Java and uses only standard JDK packages.

## Dependencies
make sure JDK 21 or later versions of JDK is installed in the environment.

## Compiling and Executing
Convenience shell scripts compile.sh and run.sh can be used for compilation and execution respectively.
In systems without shell script support, it is the easiest to use IntelliJ Idea to compile and run the Program.
